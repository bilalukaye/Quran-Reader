# Yours Quran Reader

A Quran reader for phones: IndoPak and Madani script, read like a digital book (pages are
numbered 1 to N across the whole Quran and recalculated for the chosen font size and screen),
English and Urdu meanings, word-by-word help, recitation, ribbon bookmarks, a khatam planner
with the Khatmah Dua, daily goals, Friday Al-Kahf reminders, and offline reading after the
first visit.

## Updating an existing Vercel site (GitHub)
1. Open your repository on github.com and click **Add file → Upload files**.
2. Drag in everything inside this folder (files and folders) and click **Commit changes**.
3. Vercel rebuilds automatically. Check **Deployments** until it says **Ready**.

## Sources
IndoPak text and font: DigitalKhatt IndoPak (Amine Anane), QUL / Tarteel.
Madani text: The Noble Qur'an Encyclopedia (quranenc.com).
English: Saheeh International. Urdu: Fateh Muhammad Jalandhari (public domain).
Transliteration: Tanzil. Word-by-word data and word audio: Quran.com.
Juz, ruku, hizb and sajdah data: quran-meta (Hafs). Recitation: EveryAyah.com.
Khatmah Dua: Quranic supplications from the app's Quran text; Ibn Mas'ud's hadith
(Ahmad 3712, Ibn Hibban 972); traditional supplication labelled as not authentically
attributed (al-'Iraqi, Takhrij al-Ihya 1/369).
