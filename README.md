# Yours Quran Reader

A Quran reader for phones: IndoPak and Madani script, read like a digital book (pages numbered
1 to N for the chosen font size and screen) with an optional Mushaf style, the first word of the
next page under each page, English and Urdu meanings, word-by-word help, gapless recitation,
ribbon bookmarks, a khatam planner with the Khatmah Dua, daily goals and offline reading.

## Updating an existing Vercel site (GitHub)
1. Open your repository on github.com and click Add file -> Upload files.
2. Drag in everything inside this folder (files and folders) and click Commit changes.
3. Vercel rebuilds automatically. Check Deployments until it says Ready.

## Sources
Madani (Uthmani) text: King Fahd Glorious Qur'an Printing Complex, Uthmanic Hafs text v18
(developer data, qurancomplex.gov.sa/en/techquran/dev), used exactly as published except the
trailing ayah number. The Complex's developer data has no IndoPak text.
IndoPak text and font: DigitalKhatt IndoPak (Amine Anane), QUL / Tarteel.
English: Saheeh International. Urdu: Fateh Muhammad Jalandhari (public domain).
Transliteration: Tanzil. Word-by-word data and word audio: Quran.com.
Juz, ruku, hizb and sajdah data: quran-meta (Hafs). Recitation: EveryAyah.com.
